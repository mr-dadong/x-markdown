为 Markdown 写作
精心打磨的每一个细节

从所见即所得的编辑面到斜杠命令面板，从代码高亮到章节折叠——XMD 把日常写作需要的工具收进同一个安静的工作区。

编辑面

所见即所得的写作体验

输入的瞬间就是最终的样子。标题加粗、列表缩进、引用缩进、代码高亮——一切都在同一个编辑面上完成，不需要在预览和源码之间来回切换。

  • 标题（H1–H6）、粗体、斜体、删除线、下划线
  • 有序列表、无序列表、可嵌套的任务列表
  • 引用块、分割线、文字颜色与高亮标记
  • 表格支持调整列宽，左中右对齐
  • 一键切换源码视图，随时查看 Markdown 本身

用户认证

使用 Bearer Token 进行身份验证，令牌有效期为 24 小时。

  • 登录接口返回 JWT 令牌
  • 后续请求在 Header 中携带 Authorization
  • 令牌过期后需重新登录
注意：测试环境的令牌有效期缩短为 2 小时。

响应格式

所有接口统一返回 JSON 格式。

命令系统

斜杠即命令

在任何空行敲下斜杠，命令面板就会浮在光标旁。不需要记住快捷键，也不需要翻菜单——输入关键词就能找到你要的内容块。

  • 三大分组：基础、列表与内容、媒体与链接
  • 中英文混合搜索，用习惯的叫法就能找到
  • 键盘导航：方向键选择，回车确认，ESC 取消
  • 可选显示命令辅助说明

结构

想清楚一段，就挪动一段

把光标移到任意段落左侧，拖拽柄就会出现。拖动一块到新位置，整段连同格式一起搬走；拖动标题，它身后的整个章节跟着移动。

  • 块级拖拽：段落、列表、引用、代码块都能拖
  • 拖动标题时连同下属章节一起移动
  • 章节折叠：点击标题旁的箭头收起整段内容
  • 拖拽时显示蓝色落点指示线，位置一目了然
