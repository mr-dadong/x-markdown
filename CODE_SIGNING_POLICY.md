# Code signing policy

Free code signing is provided by [SignPath.io](https://signpath.io/), with a
certificate issued by the [SignPath Foundation](https://signpath.org/).

Official release binaries are built from the public source code in this
repository. A signing request is submitted only for a reviewed release build
produced by the project's automated build workflow. Each signing request must
be approved by an authorized project approver.

## Team roles

- Committer and reviewer: [mr-dadong](https://github.com/mr-dadong)
- Approver: [mr-dadong](https://github.com/mr-dadong)

These roles may be expanded as the maintainer team grows. Changes from other
contributors must be reviewed by a project reviewer before they are included
in a signed release.

## Source and releases

- Source repository: <https://github.com/mr-dadong/x-markdown>
- Release page: <https://github.com/mr-dadong/x-markdown/releases>
- Privacy policy: [PRIVACY.md](PRIVACY.md)

Only binaries built from this repository for the XMD project may be submitted
for signing. The signing service credentials and private signing keys are not
stored in this repository.
